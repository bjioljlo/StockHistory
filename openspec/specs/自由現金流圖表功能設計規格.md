# 自由現金流圖表功能 — 設計規格

## 概述

修復主畫面「自由現金流紀錄」按鈕（`button_getFreeCF`），使其能正確繪製自由現金流（Free Cash Flow）歷史圖表。

## 計算公式

```
自由現金流 = 營業活動現金流量(OCF) + 投資活動現金流量(ICF)
```

資料來源為季財務報表中的現金流量表（SCF）。

## 架構與資料流

```mermaid
flowchart LR
    A[使用者點擊\n自由現金流紀錄] --> B[Controller_main\nbutton_FreeSCF_click]
    B --> C[Model_main\nfree_scf]
    C --> D[_create_and_draw_chart\nFreeCF_index=15]
    D --> E[FreeCF_Indicator\nnew instance]
    E --> F[Season_Report\nFS_type=SCF]
    F --> G[FinancialStatementProvider\nget_allstock_financial_statement]
    G --> H[(SQL/MongoDB/Cache)]
    E --> I[OCF + ICF = FreeCF]
    I --> J[DrawFigur\ndraw_RP]
```

## 邊界情況處理

- **無股票代號輸入**：`_create_and_draw_chart` 回傳 None 並提示「請輸入股票號碼」
- **今日日期作為結束日**：提示「今天還沒過完無資資訊」
- **無 SCF 資料**：`FreeCF_Indicator.get_ALL_Report` 回傳空 DataFrame，跳過繪圖
- **OCF 或 ICF 欄位缺失**：`check_and_convert_to_series` 處理對齊失敗後回傳空結果
